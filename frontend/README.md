# HeartRisk Studio Frontend

A lightweight React + Vite dashboard for exploring patient-level heart-risk estimates in the heart disease mortality project.

## Run locally

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local URL shown in the terminal, usually http://localhost:5173.

## Build for production

```bash
npm run build
```

This UI provides a creative clinical dashboard for manual scoring and demonstration, and is designed to be extended to a live Python or API-backed deployment later.
